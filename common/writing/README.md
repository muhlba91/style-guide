# Writing

Rules for text, as opposed to code. General principles (concision, tone, no em dashes, no emoji) live in [`../principles/`](../principles/README.md) and are not repeated here.

| File | IDs | Topic |
| --- | --- | --- |
| [`prose.md`](prose.md) | DOC-01 to 06, DOC-08 to 11, DOC-13 to 18 | Markdown mechanics, wording, agent files |
| [`repo-readme.md`](repo-readme.md) | README-01 to 11 | repository README structure and config documentation |
| [`runbook.md`](runbook.md) | RB-01 to 07 | runbooks and how-tos |
| [`commit.md`](commit.md) | COMMIT-01 to 02, COMMIT-04 to 06, COMMIT-08 to 15, COMMIT-17 to 20 | commit messages |
| [`pr-issue.md`](pr-issue.md) | PR-01 to 16, PR-18 | pull requests, issues, replies |
| [`email.md`](email.md) | MAIL-01 to 06 | email, abstract and `lean` only |

The README rules are in `repo-readme.md` because `readme.md` and `README.md` collide on case-insensitive file systems.

Weighting: 2025 and older human text is the clean signal. Text from 2026 with AI trailers weighs a bit less (0.75); untrailered text with the traits listed under "Avoid" in the files that have one weighs 0.5, caps at `prefer` and shows what the owner accepted, not what the owner writes.
